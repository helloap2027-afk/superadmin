# HELLO — Central Backend API Service

> Core backend REST API service for **HELLO** ("Discover Local. Connect Instantly.") built with NestJS, TypeScript, and Prisma ORM.

## Tech Stack
- **Framework**: NestJS 10
- **Language**: TypeScript
- **Database & ORM**: MySQL 8 / SQLite dev via Prisma ORM
- **Cache**: Redis

## Getting Started
```bash
# Install dependencies
pnpm install # or npm install

# Run development server
npm run dev # or npm run start:dev
```

The API service runs on `http://localhost:4000` by default.
Swagger docs available at `http://localhost:4000/api/docs`.
