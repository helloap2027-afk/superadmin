# HELLO — Mobile Application

> Dual-mode (Customer & Vendor) mobile application for **HELLO** ("Discover Local. Connect Instantly.") built with React Native / Expo.

## Features
- **Customer Mode**: Hyperlocal search, category discovery, one-tap calling, WhatsApp enquiries, map directions, and customer reviews.
- **Vendor Mode**: Business claiming, real-time lead inbox, staff assignment, and branch management.

## Getting Started
```bash
# Install dependencies
pnpm install # or npm install

# Start the Expo development server
npm run dev # or npx expo start
```
